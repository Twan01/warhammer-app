# Roadmap: HobbyForge

## Overview

HobbyForge is a Tauri 2 desktop app for managing a Warhammer hobby — collection,
painting projects, paint inventory, army lists, battle logs, and spending — backed
by accurate canonical 40k data and reliable backup/restore.

Phases 1–146 (v0.1.1 → v0.7.0) are shipped. Full phase detail for each milestone is
archived under `.planning/milestones/v{X.Y}-ROADMAP.md`. The next milestone is
defined via `/gsd:new-milestone`.
