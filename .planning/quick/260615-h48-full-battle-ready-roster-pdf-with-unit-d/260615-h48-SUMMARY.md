## What Was Built

### Task 1: rulesTextToPlain
- `rulesTextToPlain(html: string | null): string` in `src/lib/rulesTextToPlain.ts`
- Converts block/break tags (`</p>`, `<br>`, `<br/>`, `<br />`, `</li>`, `</div>`, `</tr>`) to newlines before delegating to existing `stripHtml`
- Collapses 2+ consecutive newlines to one, trims; null-safe
- 14 green tests

### Task 2: exportRoster assembly
- `assembleRoster()` + `RosterData` type in `src/lib/exportRoster.ts`
- Deduplicates units by `udb_unit_id` (or `ghost:<name>`) before fetching — single `getUdbUnitDetail` call per distinct id (Map cache)
- Ghost units (`udb_unit_id === null`) produce `{ detail: null, isGhost: true }` entries; units with null detail from DB kept (not dropped)
- Enhancement → unit name mapping via `army_list_unit_id`; unknown IDs fall back to `"—"`
- Detachment section assembled only when `detachment_id` is set; no DB calls when null
- All DB functions injectable via `deps` param for testing without SQLite bridge
- 13 green tests

### Task 3: generateBattleRosterPdf renderer
- Refactored `generateArmyListPdf` body into `renderSummary()` private helper (returns finalY)
- `stampFooters()` private helper stamps "Page X of Y" + "Generated by HobbyForge" on all pages
- `generateArmyListPdf` preserved unchanged (calls `renderSummary` + `stampFooters`)
- New `generateBattleRosterPdf(roster, listName, pointsLimit): Promise<ArrayBuffer>`:
  - Section A: Roster Summary via `renderSummary` (byte-for-byte identical to existing PDF)
  - Section B: Per-datasheet stat block (autoTable), ranged/melee weapon tables, abilities grouped Core/Faction/Unit; ghost/null-detail shows "Planned — no datasheet available."
  - Section C: Detachment abilities, stratagems with CP/meta line, assigned enhancements; entire section omitted when `roster.detachment === null`
  - `ensureSpace()` inner function prevents content overflow across page boundary

### Task 4: handleSavePdf rewired
- `useLocale()` hook called at component top level; `locale` closed over in `useCallback`
- `handleSavePdf` now: builds `ExportData` as before → calls `assembleRoster` → calls `generateBattleRosterPdf`
- Removed unused `generateArmyListPdf` import from `ArmyListDetailPage.tsx`
- `locale` added to `useCallback` dependency array
- Clipboard/JSON/print-preview paths untouched
