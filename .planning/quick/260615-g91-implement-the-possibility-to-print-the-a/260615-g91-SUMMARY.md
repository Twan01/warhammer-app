# Phase quick-260615-g91 Plan 01: Army List PDF Export Enrichment Summary

**One-liner:** Category-grouped PDF roster with per-category subtotals, model counts, wargear loadout lines, and page-numbered footer — using existing jsPDF + jspdf-autotable, no new dependencies.

## What Was Built

### Task 1: Presentation enrichment

- `ExportUnit.unitCategory: string | null` added — sourced from `u.unit_category` (null for ghost units)
- `ExportUnit.wargear: { weapon_name: string; quantity: number }[]` added — populated from optional `wargearByUnitId` map ([] by default)
- `exportArmyListPdf.ts` rewritten: flat Units table replaced by one autoTable per category, ordered by the same `roleOrder` array as the on-screen view (Character -> Epic Hero -> Battleline -> Infantry -> Mounted -> Beast -> Vehicle -> Monster -> Fortification -> Dedicated Transport; unknowns after, then localeCompare)
- Each category section: bold header line with category name + subtotal pts, then autoTable with columns [Models, Unit, Points, Notes]
- PDF header: title + faction/detachment/date line + summary line (total/limit, unit count, model count)
- Footer: "Page X of Y" centered + "Generated by HobbyForge" right-aligned on every page via `doc.getNumberOfPages()` / `doc.setPage()` loop

### Task 2: Wargear plumbing

- `getListWargear(listId)`: batch SQL query joining `army_list_unit_wargear` + `army_list_units` to fetch all wargear for a list in one query (ordered by army_list_unit_id, weapon_name ASC)
- `LIST_WARGEAR_KEY` + `useListWargear(listId)` hook added following per-unit wargear hook pattern
- `ArmyListDetailPage.handleSavePdf`: calls `useListWargear(list?.id)` at component top-level, builds `Map<number, ArmyListUnitWargear[]>` grouped by `army_list_unit_id`, passes as 5th arg to `formatArmyListForExport`
- PDF renders wargear as indented sub-rows within each category autoTable: `"Loadout: 5x Bolt rifle, 1x Power fist"` per unit that has selections
