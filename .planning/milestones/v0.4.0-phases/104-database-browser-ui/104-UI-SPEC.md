## Color

Sourced from existing CSS custom properties in `globals.css`. This phase operates in dark mode (app default).

| Role | CSS Token | Dark Value | Usage |
|------|-----------|------------|-------|
| Dominant (60%) | `--background` | `hsl(240 10% 3.9%)` | Page background, full-bleed canvas |
| Secondary (30%) | `--card` / `--secondary` | `hsl(240 10% 5.9%)` / `hsl(240 3.7% 15.9%)` | Faction picker panel bg, unit row hover bg, sheet overlay bg |
| Accent (10%) | `--faction-accent` | `#71717a` (default zinc-500, overridden at runtime) | Active faction highlight in picker, selected role filter badge border |
| Semantic — muted | `--muted-foreground` | `hsl(240 5% 64.9%)` | Role section labels, stat column headers, secondary text on unit rows |
| Destructive | `--destructive` | `hsl(0 72.2% 50.6%)` | Not used in this phase (read-only browser, no mutations) |

Accent reserved for:
- Active/selected faction row left-border indicator in faction picker

Special token:
- `--battle-gold` (`oklch(0.78 0.17 85)`) — NOT used in this phase (reserved for premium UX moments)

## Layout Contract

### Page Structure
Two-column layout at `md` breakpoint and above. Below `md`: stacked vertically with faction picker collapsing to a Select dropdown.

```
┌─────────────────────────────────────────────────────────┐
│  PageHeader: "Unit Database"  [Search bar — full width] │
├──────────────────┬──────────────────────────────────────┤
│  Faction Picker  │  Main Content Area                   │
│  (240px fixed)   │  - Role filter bar (horizontal)      │
│                  │  - Keyword + point range inputs       │
│  Imperium        │  - Collapsible role sections          │
│    > Aeldari     │    > CHARACTER (3)                   │
│    > Adepta...   │      UnitRow × n (virtual scroll)    │
│  Space Marines   │    > BATTLELINE (8)                  │
│    > Space Mar.. │      ...                             │
│  Chaos           │                                      │
│    > Chaos Spa.. │                                      │
│  Xenos           │                                      │
│    > Tyranids    │                                      │
└──────────────────┴──────────────────────────────────────┘
```

- Faction picker: `w-60` (240px), `border-r border-border`, `overflow-y-auto`, no virtual scroll needed (~30 factions)
- Main content: `flex-1`, `overflow-hidden`, `flex flex-col`
- Search bar: full-width `Input` at top, debounced 300ms, replaces main content with flat results list when active
- Sheet overlay: right-side `Sheet` (shadcn Sheet, `side="right"`, `className="w-[480px] sm:w-[600px]"`), opens on unit row click

### Faction Picker Internal Structure
- Alignment group header: `text-xs font-semibold uppercase tracking-wide text-muted-foreground px-3 py-2`
- Faction row: `px-3 py-2 text-sm cursor-pointer hover:bg-accent rounded-sm flex justify-between items-center`
- Active faction: `border-l-2 border-faction-accent bg-secondary` (left border accent indicator)
- Unit count badge: `text-xs text-muted-foreground` inline on the right of faction row

### Unit Row (within role sections)
Each row inside a virtualized list — fixed height `h-10` (40px) for virtual scroll accuracy.
```
[unit name — text-sm font-normal flex-1] [role badge — optional] [from N pts — text-xs text-muted-foreground w-20 text-right]
```
- Row: `flex items-center gap-3 px-4 h-10 hover:bg-secondary cursor-pointer`
- Points: always shows "from X pts" format using lowest tier value

### Role Section Headers (collapsible triggers)
- `text-xs font-semibold uppercase tracking-wide text-muted-foreground`
- Shows count: "CHARACTER (3)"
- Default open: first 3 role sections open, rest collapsed (to avoid visual overload with 50+ units)
- Chevron rotates 180° on open via `data-[state=open]:rotate-180`

### Search Results State
When search query is non-empty (after debounce):
- Faction picker hidden (`hidden`)
- Role filter bar hidden
- Flat list of matching units: each result shows `[faction name — text-xs muted] [unit name — text-sm] [role badge] [from N pts]`
- Results sorted by faction name then unit name
- "No results" state: centered empty state illustration + copy (see Copywriting)

## Datasheet Sheet Layout

Right-side Sheet, 480px wide (600px on sm+). Sections in order:

1. **Unit name** — `text-xl font-semibold` (heading scale)
2. **Faction + Role badge row** — `text-sm text-muted-foreground` + role `Badge`
3. `Separator`
4. **Stat block table** — fixed-width columns, `Display` scale for values (M, T, SV, W, LD, OC). Column headers at `Label` scale.
5. **Composition** — text line: "X–Y models. From X pts." All points tiers shown inline.
6. `Separator`
7. **Ranged Weapons** collapsible (Collapsible, default open) — table: Name | Range | A | BS | S | AP | D | Special
8. **Melee Weapons** collapsible (default open) — table: Name | Range | A | WS | S | AP | D | Special
9. `Separator`
10. **Abilities** collapsible (default open) — grouped: Core Abilities, Faction Abilities, Unit Abilities. Each ability: `text-sm font-semibold` name + `text-sm` description text.
11. **Keywords** — inline Badge list, `text-xs`, muted variant
12. **Damaged Profile** — shown only if present: threshold text + ability description

All collapsibles use `ChevronDown` with `data-[state=open]:rotate-180`.
Section label class: `text-xs font-semibold text-muted-foreground uppercase tracking-wide` (matches existing SECTION_LABEL_CLASS in PlaybookDatasheet.tsx).

## Virtual Scrolling Contract

Library: `@tanstack/react-virtual` (new dependency, per D-06).

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Item height | 40px (fixed) | UnitRow `h-10` — fixed height required for TanStack Virtual |
| Overscan | 5 | Render 5 extra items above/below viewport for smooth scroll |
| Scroll container | ScrollArea wrapping role section content | Prevents page scroll conflicts |
| Threshold for activation | Virtual scroll applied to every role section regardless of count | Consistency; TanStack Virtual is zero-overhead for small lists |
