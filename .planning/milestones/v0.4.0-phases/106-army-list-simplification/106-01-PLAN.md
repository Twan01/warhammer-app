<objective>
Rewrite army list points resolution from name-based synced cache JOINs to FK-based JOINs through units.udb_unit_id -> udb_unit_points, and remove all synced_unit_points infrastructure across the codebase.

Purpose: Eliminates fragile name-matching for points (BSData vs Wahapedia mismatches) in favor of deterministic FK-based lookups. Removes the synced cache code that is no longer needed now that the canonical unit database exists.

Output: All 17 synced_unit_points call sites updated or removed. The syncedUnitPoints.ts query module is deleted. Points resolution works via udb_unit_points FK join.
</objective>
