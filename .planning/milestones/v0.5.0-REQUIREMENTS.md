# Requirements Archive: HobbyForge v0.5.0 Settings & Preferences

**Archived:** 2026-06-11
**Status:** All 17 requirements complete

## v1 Requirements

### Infrastructure

- [x] **INF-01**: `app_settings` table (migration) with key-value storage for all settings — Complete (Phase 121)
- [x] **INF-02**: Settings query/hook layer (`useAppSettings`, `useUpdateSetting`) with React Query integration — Complete (Phase 121)
- [x] **INF-03**: Settings page with 3-tab layout (Preferences / Data / About) using shadcn Tabs — Complete (Phase 121)

### Preferences

- [x] **PREF-01**: User can set default language (EN/FR) from Settings, persisted in `app_settings` table — Complete (Phase 122)
- [x] **PREF-02**: User can pick currency (EUR/GBP/USD/CAD/AUD/JPY) from Settings; spending tracker uses selected currency — Complete (Phase 122)
- [x] **PREF-03**: User can set a default faction that loads as active on app start — Complete (Phase 122)
- [x] **PREF-04**: User can set a default army readiness points target (500/1000/1500/2000 or custom) — Complete (Phase 122)

### Hobby Defaults

- [x] **HOB-01**: User can rename the 5 painting pipeline stage labels from Settings — Complete (Phase 123)
- [x] **HOB-02**: User can customize default pre-game checklist items from Settings — Complete (Phase 123)
- [x] **HOB-03**: User can set a default mission format for new battle logs — Complete (Phase 123)

### Data Management

- [x] **DAT-01**: Settings Data tab shows a link to navigate to Data Health page — Complete (Phase 124)
- [x] **DAT-02**: User can trigger a factory reset (wipe all user data) with multi-step confirmation — Complete (Phase 124)
- [x] **DAT-03**: User can export current preferences to a JSON file — Complete (Phase 124)
- [x] **DAT-04**: User can import preferences from a previously exported JSON file — Complete (Phase 124)

### About

- [x] **ABT-01**: About tab displays app version (from package.json/tauri.conf.json) — Complete (Phase 125)
- [x] **ABT-02**: About tab displays data stats (unit count, faction count, Wahapedia data date) — Complete (Phase 125)
- [x] **ABT-03**: About tab displays credits with Wahapedia attribution and tech stack info — Complete (Phase 125)
