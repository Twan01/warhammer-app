<!-- translations_fr.json structure (from build-unit-db.ts Step 10.5 overlay) -->

translations_fr.json shape:
{
  "factions": { "SM": "Space Marines", "NEC": "Necrons", ... },
  "units": { "<datasheet_id>": "<name_fr>", ... },
  "abilities": { "<datasheet_id>:<ability_name_en>": { "name_fr": "...", "description_fr": "..." }, ... },
  "weapons": { "<datasheet_id>:<weapon_name_en>": "<name_fr>", ... },
  "keywords": { "<keyword_en>": "<keyword_fr>", ... }
}

Key: unit entries use datasheet_id as key (e.g. "000000882")
Key: weapon entries use composite key "<datasheet_id>:<weapon_name_en>" (e.g. "000000882:Guardian spear")
Key: ability entries use composite key "<datasheet_id>:<ability_name_en>"
Per STATE.md: composite key format is name-based, not line_order
</interfaces>

    Per D-09/D-10, add French translations to translations_fr.json for all matched SM, NEC, and DG units. Per D-11, skip unmatched/Legends units.

    **Unit name translations (units section):**
    For each matched unit (those that exist in unit_database.json for factions SM, NEC, DG), add an entry in the "units" object:
      "<datasheet_id>": "<french_unit_name>"

    Use the French Wahapedia site (wahapedia.ru with French locale) as the primary source for French names per D-10. For standard Warhammer units, use the established French terminology:
    - Space Marines unit names are generally kept in English/Gothic in French GW publications (e.g., "Intercessors" stays "Intercessors", "Captain" becomes "Capitaine", "Chaplain" becomes "Aumônier", "Librarian" becomes "Archiviste", "Apothecary" becomes "Apothicaire", "Techmarine" becomes "Techmarine", "Lieutenant" stays "Lieutenant", "Sergeant" stays "Sergent")
    - Named characters keep their English names (e.g., "Marneus Calgar" stays "Marneus Calgar", "Roboute Guilliman" stays "Roboute Guilliman")
    - Vehicle names are typically kept in English (e.g., "Repulsor" stays "Repulsor", "Gladiator" stays "Gladiator")
    - "Squad" translates to "Escouade", "Team" to "Equipe"
    - Necron unit names are typically kept in English (Overlord stays "Overlord" but "Nécron" is used as the faction adjective)
    - Death Guard names are typically English with French article where applicable

    Fetch French Wahapedia pages for representative units from each faction to verify translations. Use wahapedia.ru/wh40k10e/factions/{faction_name_in_url}/ to find the French unit listing.

    **Weapon name translations (weapons section):**
    For each weapon of matched units, add an entry:
      "<datasheet_id>:<weapon_name_en>": "<french_weapon_name>"

    Standard weapon translations:
    - "bolt rifle" = "fusil bolter", "heavy bolt rifle" = "fusil bolter lourd"
    - "power sword" = "epee energetique", "power fist" = "gantelet energetique"
    - "chainsword" = "tronconneuse", "thunder hammer" = "marteau tonnerre"
    - "lascannon" = "canon laser", "plasma gun" = "fusil a plasma"
    - "melta gun" = "fusil de fusion", "flamer" = "lance-flammes"
    - "bolt pistol" = "pistolet bolter", "plasma pistol" = "pistolet a plasma"
    - "close combat weapon" = "arme de corps a corps"
    Use proper French accents (e for accent aigu, etc.) in actual entries.

    **Ability name translations (abilities section):**
    For each named ability (ability_type == "Datasheet", non-empty name) of matched units, add:
      "<datasheet_id>:<ability_name_en>": { "name_fr": "<french_name>", "description_fr": null }

    Per D-09, description_fr is optional — focus on name_fr. Common ability translations:
    - "Leader" = "Meneur", "Deadly Demise" = "Trépas Mortel", "Deep Strike" = "Frappe en Profondeur"
    - "Feel No Pain" = "Insensible à la Douleur", "Stealth" = "Furtivité"
    - "Oath of Moment" (SM) = "Serment du Moment", "Reanimation Protocols" (NEC) = "Protocoles de Réanimation"
    - "Disgustingly Resilient" (DG) = "Répugnant de Résistance", "Nurgle's Gift" = "Don de Nurgle"

    Skip abilities where ability_type is "Core" or "Faction" with empty name (these are placeholders per Pitfall 2).

    **Scale estimate:** ~182 SM + ~53 NEC + ~36 DG = ~271 unit entries, plus their weapons (~2,472 total across 3 factions but many share common names) and named abilities. For weapons and abilities, group by English name first — many units share identical weapon names (e.g., "bolt rifle" appears on dozens of SM units), so create the entry once per (unit_id, weapon_name) composite key.

Add them to the existing translations_fr.json preserving the current entries (3 Custodes units, 1 ability, 1 weapon, faction names, keywords).
