## Component Inventory

### Net-New Components

**`LocaleToggle`** — `src/components/common/LocaleToggle.tsx`

- Two-segment inline toggle: `EN` | `FR`
- Collapsed sidebar: show only the active locale code (e.g., `EN`) as a ghost icon-sized button with a tooltip "Switch to French / Switch to English"
- Expanded sidebar: show both labels side-by-side as a pill toggle — active segment has `bg-secondary rounded-sm px-2 py-0.5`, inactive segment is plain text at `text-muted-foreground`
- No dropdown. No switch/checkbox. Text-only pill per CONTEXT.md D-05 + specifics note.
- Placement: between collapse toggle row and the Settings border-top, in the existing `px-2 pb-1` div. Rendered before the `<Button>` collapse toggle within that div, OR as a separate row immediately above it.
- On click: call `useLocaleStore().setLocale()`, which invalidates all `udb_*` React Query keys

**`useLocaleStore`** — `src/stores/localeStore.ts`

- Zustand `persist` store, localStorage key `"app:locale"`
- Shape: `{ locale: 'en' | 'fr', setLocale: (l: 'en' | 'fr') => void }`
- Default: `'en'`
- Pattern: clone `gameDayStore.ts` persist wrapper, clone `useSidebarCollapsed.ts` localStorage read pattern for SSR safety

## Interaction Contract

### Locale Toggle — Expanded Sidebar

```
[ EN | FR ]
```

- Both labels always visible
- Active segment: `bg-secondary text-foreground rounded-sm px-2 py-0.5 text-xs font-semibold`
- Inactive segment: `text-muted-foreground text-xs font-semibold cursor-pointer hover:text-foreground`
- Transition: React Query cache invalidation is async; no loading spinner needed — data refetches in background, existing cached data shows until new data arrives (staleTime 5min, but locale change forces refetch via key change)
- No confirmation dialog. Locale switch is reversible instantly.

### Locale Toggle — Collapsed Sidebar

- Show only active locale code as a ghost button (32x32px, matches existing collapse button sizing)
- `aria-label="Switch to French"` / `aria-label="Switch to English"` depending on current locale
- Tooltip on hover: "Switch to French" / "Switch to English"

### Bilingual Data Display (no new UI component)

- When locale = `fr` and `name_fr` is populated: French name renders
- When locale = `fr` and `name_fr` is null: English name renders silently (COALESCE fallback)
- No "[untranslated]" label, no asterisk, no indicator — clean fallback per CONTEXT.md specifics
- FTS5 search: unchanged input UX; results match both EN and FR names automatically — no UI change required
