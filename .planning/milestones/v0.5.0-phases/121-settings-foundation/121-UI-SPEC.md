## Spacing Scale

Declared values (multiples of 4 — standard 8-point scale applied throughout):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tab indicator gaps |
| sm | 8px | Compact element spacing, between label and control |
| md | 16px | Default element spacing, intra-section gaps |
| lg | 24px | Section padding, page content padding (p-6 = 24px matches DataHealthPage pattern) |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Reserved; not used in this phase |
| 3xl | 64px | Reserved; not used in this phase |

Exceptions: none for this phase. Settings shell is a single-column scrollable page — no touch targets requiring 44px override.

## Typography

Follows project-wide Geist Variable type scale. Identical to DataHealthPage and all other feature pages:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 | Tab placeholder content, descriptive copy, tab labels inside shadcn Tabs trigger |
| Heading (section) | 18px (text-lg) | 600 (semibold) | 1.2 | Section sub-titles within tab panels, placeholder headings |
| Page title | 20px (text-xl) | 600 (semibold) | 1.2 | "Settings" h1 — matches DataHealthPage `text-xl font-semibold` |

Declared weights: 2 — 400 (normal) and 600 (semibold).

Source: DataHealthPage.tsx pattern `text-xl font-semibold` (h1) and `text-lg font-semibold` (h2).

## Color

All values reference the project's CSS custom properties. App is dark-mode-first (`.dark` class active at runtime).

| Role | CSS Token | Dark Mode Value | Usage |
|------|-----------|----------------|-------|
| Dominant (60%) | `hsl(var(--background))` | hsl(240 10% 3.9%) near-black | Page background, main content area |
| Secondary (30%) | `hsl(var(--card))` | hsl(240 10% 5.9%) dark zinc | Tabs container surface, any future card sections |
| Accent (10%) | `hsl(var(--primary))` | hsl(0 0% 98%) off-white | Active tab indicator, active tab label |
| Muted text | `hsl(var(--muted-foreground))` | hsl(240 5% 64.9%) zinc-400 | Placeholder content copy inside inactive tabs |
| Destructive | `hsl(var(--destructive))` | hsl(0 72.2% 50.6%) red | Not used in Phase 121 shell; reserved for Phase 124 factory reset |
| Border | `hsl(var(--border))` | hsl(240 3.7% 15.9%) | Tab list underline, separator between tabs and content |

Accent reserved for: active tab trigger indicator (TabsList active state) only. No other use in this phase.

Source: globals.css .dark block — all tokens verified present.

## States & Interactions

| State | Trigger | Behavior |
|-------|---------|----------|
| Tab switch | Click TabsTrigger | Immediate — no async, content swaps inline |
| Loading | `useAppSettings` pending | Show `<Skeleton className="h-4 w-48" />` inside tab content area |
| Error | `useAppSettings` rejects | Show inline error text: "Could not load settings. Restart the app to try again." with `text-destructive` color |
| Default active | Page mount | Preferences tab active |

No sheets, dialogs, or drawers in this phase. All interaction is tab navigation only.
