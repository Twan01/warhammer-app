## Spacing Scale

Standard 8-point scale — already enforced across the codebase. The tab content
area uses `mt-4` (16px) consistent with the Preferences and Data tabs in `page.tsx`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline label-to-value pairs |
| sm | 8px | Intra-section item gaps (`gap-2`) |
| md | 16px | Default element spacing; `mt-4` for tab content top margin |
| lg | 24px | Section-to-section vertical gap (`space-y-6`) |
| xl | 32px | Not used in this tab |
| 2xl | 48px | Not used in this tab |
| 3xl | 64px | Not used in this tab |

Exceptions: none. The three content sections (App Identity, Data Stats, Credits)
use `space-y-6` vertical stacking — 24px gaps between sections.

## Typography

Follows project-wide type scale. Sizes are in Tailwind utility terms mapped to
their pixel equivalents.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Page heading | 20px (`text-xl`) | 600 (`font-semibold`) | 1.2 | "Settings" page title (inherited, not new) |
| Section heading | 18px (`text-lg`) | 600 (`font-semibold`) | 1.2 | "About HobbyForge", section sub-headings |
| Body / label value | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 | Stat values, attribution paragraphs |
| Micro label | 12px (`text-xs`) | 400 (`font-normal`) | 1.4 | `text-muted-foreground` uppercase tracking-wider stat labels (matches `InfoItem` pattern in `VersionInfoCard`) |

Two weights only: 400 (regular) and 600 (semibold). No other weights used.

## Color

All values are CSS custom properties from `globals.css` dark-mode tokens (dark mode
is the runtime mode for this app).

| Role | Token | Hex Equivalent (dark) | Usage |
|------|-------|----------------------|-------|
| Dominant (60%) | `hsl(var(--background))` | ~`#0a0a0f` | Page and tab background surface |
| Secondary (30%) | `hsl(var(--card))` / `hsl(var(--secondary))` | ~`#0f0f17` | Not used for card wrappers (D-02: no card wrappers); used only for tab strip background |
| Accent (10%) | `var(--faction-accent)` (default zinc-500 `#71717a`) | faction-specific | Reserved for: interactive link color if any external URL is added in future (none in this phase) |
| Muted text | `hsl(var(--muted-foreground))` | ~`#8a8a99` | Section sub-labels, attribution body text, "Not imported yet" state |
| Destructive | `hsl(var(--destructive))` | ~`#c0392b` | Not used — this tab has no destructive actions |

Accent is NOT used in this tab. This is a read-only informational view.

Reuse the `InfoItem` display pattern from `VersionInfoCard.tsx` — NOT the component
itself (D-08 decision). Inline the same structure directly in `AboutTab.tsx`:

## Layout Contract

The `AboutTab` component renders inside `<TabsContent value="about" className="mt-4">`.
Content flows in a single vertical column with `space-y-6` between the three sections.
No card wrappers (D-02). No horizontal split.

### Section 1 — App Identity (top)

```
[App name: "HobbyForge"]        text-lg font-semibold
[One-line description]          text-sm text-muted-foreground
[App version: "v{version}"]     text-sm — Skeleton while loading
```

- App name: "HobbyForge"
- Description: "Your personal Warhammer hobby command center."
- Version row label: "Version" (micro-label style), value: `v{appVersion}` or Skeleton

### Section 2 — Data Statistics (middle)

```
[Section label: "Unit Database"] text-sm font-semibold
[Stat grid — flex-wrap gap-8]
  Units:    {unit_count} units across {faction_count} factions — Skeleton while loading
  Data date: {formatBuiltAt(built_at)} — Skeleton while loading
  Game system: Warhammer 40,000 10th Edition — shown only when udbMeta present
```

- "Not imported yet" is shown as `text-sm text-muted-foreground` when `udbMeta` is null.
- `formatBuiltAt()` helper is imported or co-located (already exists in `VersionInfoCard.tsx` — copy into `AboutTab.tsx` since the component is not shared).

### Section 3 — Credits & Attribution (bottom)

```
[Section label: "Credits"]     text-sm font-semibold
[Attribution paragraph]        text-sm text-muted-foreground
[Tech stack list]              text-sm text-muted-foreground
```

Attribution paragraph (exact copy — see Copywriting Contract below).
Tech stack: rendered as a simple comma-separated inline list, not a bullet list.

## Interaction Contract

| Interaction | Behaviour |
|-------------|-----------|
| Tab mount | `getVersion()` called once via `useEffect` — result stored in local `useState`. `useUdbMeta()` hook called for stats. |
| Version loading | Show `Skeleton className="w-16 h-4"` while `appVersion` is null. |
| Stats loading | Show `Skeleton className="w-24 h-4"` per stat while `udbMetaLoading` is true. |
| No udb data | Render "Not imported yet" in `text-muted-foreground` for Units/Data Date/Game System rows. |
| Version error | On `getVersion()` rejection, set `appVersion = "unknown"`. No error toast. |
| No hover/focus states | All content is static display — no interactive elements. |

---

## States Required

| State | Trigger | Visual Treatment |
|-------|---------|-----------------|
| Loading | `appVersion === null` OR `udbMetaLoading === true` | Per-field `Skeleton` (not full-tab skeleton) |
| Loaded — data present | `udbMeta` has row | Display all three stat values normally |
| Loaded — no data | `udbMeta` is null/undefined | "Not imported yet" text for stats section |
| Version unknown | `getVersion()` rejected | Display literal string "unknown" |

No full-tab error state needed (D-03 and CONTEXT.md: stats section gracefully degrades).
