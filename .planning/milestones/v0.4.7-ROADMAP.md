# Milestone v0.4.7: Wahapedia Pipeline & Full Data Import

**Status:** SHIPPED 2026-06-09
**Phases:** 116-120
**Total Plans:** 10

## Overview

Replace the BSData-dependent build pipeline with a Wahapedia-only pipeline that auto-downloads CSVs and imports all available game data — points, stratagems, enhancements, and detachment abilities — with 100% unit coverage. Wire all new data into existing UI surfaces (Game Day, Rules Hub, Army Lists, PlaybookTab).

## Phases

**Goal**: The build pipeline reliably parses all Wahapedia CSVs and produces a clean, deduplicated unit dataset

**Requirements**: PF-01, PF-02, PF-03, PF-04
**Plans**: 2 plans

Plans:

- [x] 116-01-PLAN.md — BOM fix in CSV parser + Wahapedia auto-download command

## Milestone Summary

**Key Decisions:**

- Separate download:wahapedia from build:udb for deterministic builds
- Nullable FK for universal stratagems (faction_id NULL) — avoids dummy faction rows
- Content hash dedup for universal stratagems appearing across factions
- staleTime: Infinity for game data hooks (data only changes on rebuild/import)
- HTML sanitization via sanitizeHtml utility for stratagem/enhancement descriptions
- Shared stratagemStyles utility for consistent phase-colored stratagem cards

**Issues Resolved:**

- BOM characters silently dropping CSV rows in new file imports
- BSData XML matching limited to 60% coverage — Wahapedia cost CSV achieves 99.8%
- Empty stubs in Game Day, Rules Hub, Army Lists, PlaybookTab replaced with real data
- Enhancement points required manual input — now auto-resolved from canonical database

**Issues Deferred:**

- French translations for stratagems/enhancements (future milestone)
- Sub-faction derivation from Wahapedia CSV (static mapping sufficient)
- Competitive list validation with detachment restrictions (not in scope)

**Technical Debt Incurred:**

- Datasheets_models_cost.csv not in REQUIRED_CSVs validation array (raw error if missing)
- useSharedAbilitiesByFaction retained as empty-array stub (intentional scope boundary)
- useDetachmentAbilitiesByDetachment fires unnecessary query with empty string when no detachment selected
- Phase 119 Nyquist validation incomplete
