## Milestone Summary

**Key Decisions:**

- translations_fr.json overlay uses composite key format for abilities/weapons (name-based, not line_order)
- SUB_FACTION_MAP covers 17 entries: 11 SM chapters, 4 CSM warbands, 2 Aeldari sub-factions
- Sub-factions denormalized as TEXT on udb_units only — new faction rows break FK backfill
- FTS5 DROP+CREATE with FR names piped into keywords column (can't ALTER FTS5)
- French _fr fields travel in unit_database.json with #[serde(default)] in Rust
- Game Day OPG keys use unit_id:ability_name composites (not AUTOINCREMENT)
- Coverage badges use live SQL query (not static JSON)
- 85% Wahapedia coverage unachievable: BSData covers 62% of datasheets; match rate is 96.9%

**Issues Resolved:**

- Points match rate improved from 37% to 96.9% (BSData match rate)
- PlaybookTab null stubs replaced with canonical data
- Game Day OPG persistence stabilized with composite keys
- Army list validation enhanced with DEDICATED TRANSPORT and EPIC HERO checks

**Issues Deferred:**

- EXT-01..03: Leader attachment targets, enhancement data, stratagems in canonical DB
- ADV-01..02: Unit comparison view, faction overview page
- FR-EXT-01..02: French ability/weapon text, full app UI translation

**Technical Debt Incurred:**

- Duplicate WeaponTable in DatasheetPointsTab.tsx (pre-existing, not in v0.4.2 scope)
- DQ-05 Wahapedia coverage 60.1% (BSData limitation, not pipeline issue)
- 15 human verification items pending across all 4 phases
