# Milestone v0.4.5: Data Quality Audit & Pipeline Improvement

**Status:** ✅ SHIPPED 2026-06-03
**Phases:** 112-115
**Total Plans:** 7

## Overview

Audit canonical unit data for priority factions against official sources, fix all errors found, improve the automated build pipeline to prevent those errors from recurring, and fix sub-faction filtering to include parent faction units.

## Phases

### Phase 112: Build Pipeline Hardening

**Goal**: The build script is production-grade — it reports coverage, builds deterministically, validates its own config, and fails loudly when data quality falls below threshold
**Depends on**: Nothing (first phase of milestone)
**Requirements**: BPH-01, BPH-02, BPH-03, BPH-04, BPH-05
**Plans:** 2/2 plans complete

Plans:
- [x] 112-01-PLAN.md — Shared library extraction (bsdata.ts) and script rewiring
- [x] 112-02-PLAN.md — Coverage reporting, deterministic output, alias validation, threshold

**Details:**
- Extracted shared BSData parsing library (`scripts/lib/bsdata.ts`) with readCsvFile, readBsdataCatFiles, parseBsdataModelCounts, matchUnit
- Both build-unit-db.ts and update-unit-database.ts use identical 3-pass matching pipeline
- Per-faction coverage table with Matched/Exact/Norm/Alias columns
- Deterministic output sorting of all 8 arrays before content hash
- Alias validation with used/unused/unknown-target summary
- MIN_COVERAGE_PCT = 55 threshold with process.exit(1) on regression

## Milestone Summary

**Key Decisions:**
- allBsdataNames collects from ALL BSData units (not just matched) — alias unused detection requires it
- MIN_COVERAGE_PCT=55→58 conservative ratchet (coverage gap is structural at 60.1%)
- No new aliases needed: all missing units are Wahapedia-only (no BSData equivalent)
- Alias keys must use straight apostrophe (U+0027) to match BSData XML entity encoding
- Gothic/Latin weapon names kept as-is in French — standard GW practice
- Dual-site fix for sub-faction: SQL + client-side both needed for their respective surfaces

**Issues Resolved:**
- Weapon range, keywords, and grouping data incorrect due to wrong CSV column names
- Stale Emperor's Champion alias with curly apostrophe mismatch
- Sub-faction filter excluding parent faction's generic units

**Issues Deferred:**
- Extended faction audits for remaining 22 factions (EFA-01..03)
- French ability description full text (weeks of manual data entry)

**Technical Debt Incurred:**
- French translation unit names lack accents (cosmetic, not functional)
- Phase 112 Nyquist validation missing (3/4 compliant)
