**Status:** SHIPPED 2026-06-11

## Overview

Comprehensive Settings page with tabbed navigation (Preferences / Data / About) centralizing app configuration, hobby defaults, data management shortcuts, and version info. All settings persist to app_settings SQLite key-value table with React Query integration.

## Milestone Summary

**Key Decisions:**
- DDL-only migration 044 with no seed data (defaults in hook layer, boot-loop prevention per migration 038 precedent)
- INSERT OR REPLACE upsert pattern for app_settings (idiomatic SQLite)
- localeStore gutted to useLocale() shim reading from app_settings (Zustand store removed)
- ActiveFactionContext reads default_faction_id from app_settings on cold start (localStorage fallback preserved)
- useArmyReadinessTarget migrated from localStorage to app_settings with session-only override
- HobbyPipeline renders dynamic bucket labels from app_settings (only bucket-label consumer per D-05)
- BattleLogSheet pre-fills mission from default_mission_format on create only (D-11)
- gameDayStore exports getDefaultChecklist async + setDefaultChecklist action with existing-session guard
- Preference export/import uses 7-key allowlist validation for safety
- Factory reset via Rust command with safety backup before deletion

**Issues Resolved:**
- Locale management migrated from Zustand persist to app_settings for consistency
- Currency formatting centralized through useCurrencyPreference hook
- Army readiness target migrated from localStorage to app_settings

**Technical Debt Incurred:**
- getBucketLabel() in src/lib/stageLabel.ts exported but never called in production (dead code)
