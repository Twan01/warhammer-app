### ⚠ Integration Warning (non-blocking) — Rules Hub leader display

`src/features/rules-hub/DatasheetPointsTab.tsx` → `useLeaderTargetsByFaction` (`useBsdataFaction.ts`) → `bsdataExtended.ts` still query the **dead `synced_leader_targets` table**, which has no writer in the Wahapedia-only pipeline. The "Leader — Can attach to" section in the Rules Hub datasheet view therefore renders empty for every user. The empty-array guard hides the section (no crash). This is the unfinished tail of Phase 136's deferred CR-01 — Phase 137 migrated `LeaderAttachmentSheet` but not `DatasheetPointsTab`.

**Fix:** repoint `DatasheetPointsTab` to a faction-scoped query against `udb_leader_targets` (JOIN `udb_units` for leader and target names, `WHERE leader_u.faction_id = $1`).
