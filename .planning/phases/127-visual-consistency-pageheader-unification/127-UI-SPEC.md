## Spacing Scale

Standard 8-point scale. All page containers must use `p-6 flex flex-col gap-6`.

| Token | px Value | Tailwind Class | Usage |
|-------|----------|----------------|-------|
| xs | 4px | gap-1 / p-1 | Icon gaps, inline spacing |
| sm | 8px | gap-2 / p-2 | Compact element spacing |
| md | 16px | gap-4 / p-4 | Icon-pill internal padding |
| lg | 24px | gap-6 / p-6 | Page padding (standard — all pages) |
| xl | 32px | gap-8 / p-8 | NOT used — Spending page migrates away from this |
| 2xl | 48px | gap-12 | NOT used — Spending page migrates away from this |
| 3xl | 64px | py-16 | Empty state vertical padding |

**Phase-specific enforcement:**
- `p-6 gap-6` is the canonical page container pattern. Source: CONTEXT.md D-04, D-05.
- Spending page must change from `p-8 gap-12` → `p-6 gap-6`. Source: VIS-04.
- Data Health and Settings pages must change from `space-y-6` → `flex flex-col gap-6`. Source: VIS-09.
- Empty states use `py-16` for vertical centering with `flex flex-col items-center justify-center gap-3`. Source: FactionsEmptyState reference pattern.

Exceptions: none.

## Typography

Declared sizes are drawn from existing globals.css and PageHeader component. No new sizes introduced in this phase.

| Role | Size | Tailwind Class | Weight | Line Height | Usage |
|------|------|----------------|--------|-------------|-------|
| Page heading | 30px (text-3xl) | text-3xl | 600 (font-semibold) | 1.2 | PageHeader `<h1>` — all pages |

```
text-3xl font-semibold tracking-tight
```
Apply verbatim to Rules Hub and Unit Database pages via the PageHeader component drop-in.

## Color

All values are CSS custom property tokens from globals.css. Dark-mode-first app (zinc theme).

| Role | Token | Dark Value (approx.) | Usage |
|------|-------|----------------------|-------|
| Dominant (60%) | `hsl(var(--background))` / `bg-background` | zinc-950 (#09090b) | Page backgrounds |
| Secondary (30%) | `hsl(var(--card))` / `bg-card` | zinc-900 (#18181b) | Cards, sidebar, nav, popovers |
| Muted surface | `hsl(var(--muted))` / `bg-muted` | zinc-800 (#27272a) | Input backgrounds, muted areas |
| Muted text | `hsl(var(--muted-foreground))` / `text-muted-foreground` | zinc-400 | Subtitles, labels, secondary text |
| Accent (10%) | `hsl(var(--accent))` / `bg-accent` | zinc-800 | Hover states, selected items only |
| Destructive | `hsl(var(--destructive))` / `text-destructive` | red-600 | Error text, destructive action labels |
| Border | `hsl(var(--border))` / `border-border` | zinc-800 | Dividers, table lines |
| Border dimmed | `border-border/40` | zinc-800 at 40% opacity | PageHeader separator line |

**Accent reserved for:** hover states on interactive rows and selected sidebar items only. Not used for decorative elements.

**Status dot colors** (VIS-06 — replaces all hardcoded hex):

| State | Old (hardcoded hex) | New (Tailwind class) |
|-------|--------------------|-----------------------|
| Owned / available | `style={{ backgroundColor: "#22c55e" }}` | `className="bg-green-500"` |
| Running low / amber | `style={{ backgroundColor: "#f59e0b" }}` | `className="bg-amber-500"` |
| Missing / error | `style={{ backgroundColor: "#ef4444" }}` | `className="bg-red-500"` |

These are Tailwind semantic utility classes — they are defined outside CSS variables and work correctly in both light and dark mode without custom tokens.

**Icon-pill background** (VIS-05, VIS-08 empty states):
```
rounded-xl bg-muted/40 p-4
```
Use `bg-muted/40` (not `bg-muted`) for the softer appearance matching FactionsEmptyState.

| Element | Copy | Requirement |

| Paints filtered empty body | "Try adjusting or clearing your filters to see more results." | VIS-05 |
| Paints filtered empty CTA | "Clear filters" (ghost button, existing behavior) | VIS-05 |

**Empty state heading grammar rule:** Sentence case, no trailing period. Max 5 words.
**Empty state body grammar rule:** Full sentence, trailing period. Max 15 words. Must include a next step or action hint.
**Subtitle grammar rule:** Sentence case, no trailing period. Max 10 words. Active or descriptive — not marketing copy.

Destructive actions: none in this phase.
Error states: none new in this phase.

## Interaction Contract

This phase is markup/token replacement only. No new interactive behaviors are introduced.

| Interaction | Behavior | Notes |
|-------------|----------|-------|
| PageHeader border-b | Static visual separator — `border-b border-border/40` | No hover, no click |
| Status dots (RecipeCard, SectionedTimeline) | Static colored circles — class swap only | No behavior change |
| Paints filtered empty "Clear filters" | Calls existing `clearAll()` — no change to behavior | Visual container change only |
| Page layout spacing | Visual tightening — `p-6 gap-6` — no behavior change | Spending page narrows slightly |
| Button icons (Dashboard) | `h-4 w-4 mr-2` — visual alignment only | No behavior change |

No loading states, no skeleton states, no optimistic updates, no toasts, and no error boundaries are added or changed in this phase.
