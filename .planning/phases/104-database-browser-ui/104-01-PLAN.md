    Create `src/db/queries/unitDatabase.ts` (per D-13) with 4 exported async functions, all using `getDb()` from `@/db/client` (NEVER `getRulesDb()`):

    1. `getUdbFactions()` — SELECT id, name, short_name FROM udb_factions ORDER BY name ASC. Return type `UdbFaction[]` with interface `{ id: string; name: string; short_name: string | null }`.

    2. `getUdbUnitsByFaction(factionId: string)` — SELECT from udb_units with subqueries for MIN(points) from udb_unit_points as `base_points`, MIN(min_models) from udb_unit_composition as `min_models`, MAX(max_models) as `max_models`. WHERE faction_id = $1, ORDER BY role, name ASC. Return type `UdbUnitSummary[]` with interface `{ id: string; name: string; role: string | null; base_points: number | null; min_models: number | null; max_models: number | null }`.

    3. `getUdbUnitDetail(unitId: string)` — First SELECT from udb_units WHERE id = $1. If no row, return null. Then Promise.all 6 parallel selects: udb_unit_models (ORDER BY line_order), udb_unit_weapons (ORDER BY weapon_group, line_order), udb_unit_abilities (ORDER BY line_order), udb_unit_keywords (ORDER BY is_faction DESC, keyword), udb_unit_points (ORDER BY model_count), udb_unit_composition. Return type `UdbUnitDetail | null` with interface containing unit, models, weapons, abilities, keywords, points, composition arrays.

    4. `searchUdbUnits(query: string)` — If query.trim().length < 2, return []. Sanitize FTS5 special chars by stripping `"'*^()` then append `*` for prefix search. SELECT unit_id, name, faction_name, keywords FROM udb_search WHERE udb_search MATCH $1 LIMIT 50. Return type `UdbSearchResult[]` with interface `{ unit_id: string; name: string; faction_name: string; keywords: string }`.

    Export all interfaces (UdbFaction, UdbUnitSummary, UdbUnitDetail, UdbSearchResult, UdbModel, UdbWeapon, UdbAbility, UdbKeyword, UdbPointsTier, UdbComposition) so downstream components can import them.
