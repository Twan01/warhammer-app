## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Button internal padding, compact rows |
| md | 16px | Card internal padding (`px-4 py-3`), form fields |
| lg | 24px | Section gaps, sheet body padding (`gap-4` inside sheet) |
| xl | 32px | Page section breaks |
| 2xl | 48px | Major section breaks (between PlaybookTab sections) |
| 3xl | 64px | Page-level empty state vertical centering (`py-8`) |

Exceptions: Touch target minimum 44px for the CP "Spend" button in GameDayStratagemCard. Combobox trigger width uses `w-[--radix-popover-trigger-width]` (responsive, not fixed).

Source: Observed from `StrategemsTab.tsx`, `GameDayStratagemCard.tsx`, `EnhancementPickerSheet.tsx`

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label | 12px (`text-xs`) | 400 (regular) | 1.4 |
| Card title / stratagem name | 14px (`text-sm`) | 500 (`font-medium`) | 1.4 |
| Page heading | 30px (`text-3xl`) | 600 (`font-semibold`) | 1.2 |

Rules: Body is `text-sm` throughout all card-based views. Page headings (`<h1>`) use `text-3xl font-semibold tracking-tight`. Section headings within cards (phase group headers, enhancement section headers) use `text-sm font-medium`. Counts and metadata use `text-xs text-muted-foreground`. No sizes outside this set.

Source: `RulesHubPage.tsx` line 99, `StrategemsTab.tsx` lines 104/147, `EnhancementPickerSheet.tsx` line 159

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` — zinc-950 dark | Page background, sheet background |
| Secondary (30%) | `hsl(var(--card))` — zinc-950/5.9% dark | Card surfaces (`bg-card`), collapsible trigger backgrounds |
| Accent (10%) | `hsl(var(--primary))` — zinc-50 (light), zinc-950 (dark) | Annotated card left border (`border-l-primary`), selected phase filter chips, "Assigned" enhancement badge |

### New component: `PlaybookDetachmentAbilities`

Location: `src/features/units/PlaybookDetachmentAbilities.tsx`

Structure:
- Outer: `<Collapsible defaultOpen>` wrapping a titled section
- Trigger: `text-sm font-medium` label "Detachment Abilities" + chevron
- Content: `flex flex-col gap-2` list of ability cards
- Ability card: `rounded-md border bg-card px-4 py-3` with ability name (`text-sm font-medium`) and HTML description (`text-sm text-muted-foreground` wrapper with `dangerouslySetInnerHTML`)
- Detachment name grouping header (when showing all detachments): `text-xs font-semibold text-muted-foreground uppercase tracking-wide`

Placement in `PlaybookTab.tsx`: After `<PlaybookRules />`, before `<TierManager />`.

### HTML description rendering pattern

All description fields from `udb_stratagems.description`, `udb_enhancements.description`, and `udb_detachment_abilities.description` contain HTML with `kwb`-class spans, `<br>` tags, and `<b>` tags (WHEN/TARGET/EFFECT structure).

Render using:
```tsx
<div
  className="prose-none text-sm text-muted-foreground [&_b]:font-semibold [&_b]:text-foreground [&_.kwb]:text-foreground"
  dangerouslySetInnerHTML={{ __html: description }}
/>
```

This matches the existing `dangerouslySetInnerHTML` pattern used in `PlaybookTab.tsx` for rules display (D-19 from CONTEXT.md).

### Enhancement card addition: description display

The existing `EnhancementPickerSheet.tsx` enhancement card (`rounded-md border p-3`) shows name + points badge. Phase 120 adds:
- Description rendered as HTML immediately below the name, using the pattern above
- Description is collapsed by default if over 3 lines; use `line-clamp-3` with expand-on-click affordance (tap card row to expand)
- Points badge reads `{cost} pts` for positive cost; `Free` when cost is 0

## Interaction States

### DetachmentPicker (DET-03)

| State | Visual |
|-------|--------|
| Faction not selected | Button disabled, label "Select a faction first", `text-muted-foreground` |
| Loading detachments | Combobox shows existing spinner from `CommandEmpty` |
| No detachments found | `CommandEmpty` text: "No detachments found for this faction." |
| Detachment selected | Button shows detachment name, clear X button appears |
| Clear clicked | Confirmation: none (non-destructive reset) |

### StrategemsTab Game Day (STR-03)

| State | Visual |
|-------|--------|
| No detachment selected | `text-center py-8 text-sm text-muted-foreground` paragraph |
| Loading | 3 × `Skeleton h-12 w-full` (existing pattern) |
| No stratagems for detachment | `text-center py-8 text-sm text-muted-foreground` paragraph |
| Data loaded | Phase-grouped `Collapsible` sections, `defaultOpen` |
| CP spent | `spendCp` action via existing `useGameDayStore` — no new visual |

Empty state copy (no detachment): "No detachment selected — select one in your army list to see stratagems." (existing — preserve exactly)
Empty state copy (detachment set, no data): "No stratagems found for this detachment." (existing — preserve exactly)

### Rules Hub Stratagems tab (STR-04)

| State | Visual |

| State | Visual |
|-------|--------|
