## Spacing Scale

Identical to Phase 143. Multiples of 4 throughout.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline badge padding |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`) — step list row pad |

| 3xl | 64px | Not used in this phase |

Exceptions:

  SlotFillDialog (max-w-md).
- "N colour slots unfilled" line in PaintReadinessBanner: sits on its own row
  inside the existing `px-4 py-3` banner padding; no additional spacing.

### Swatch rendering — Phase 145 additions

**StepFocalView large swatch (40×40px):**

| State | Visual |
|-------|--------|
| Resolved paint (filled slot or plain step) | `h-10 w-10 rounded-full border-2 border-background ring-2 ring-border` filled with `paint.hex_color` — unchanged |
| Paintless step (intentionally no paint) | `<p className="text-sm text-muted-foreground">(no paint)</p>` — unchanged |
| **Unfilled slot (technique step, slot not yet assigned)** | `h-10 w-10 rounded-full border-2 border-dashed border-muted-foreground bg-transparent` + label `text-xs text-muted-foreground` below: "Slot unfilled — tap to assign" |

The unfilled-slot swatch is interactive (wraps in a `<button type="button">`) to
open the inline mini-dialog. It must be visually distinct from both the resolved
swatch (solid fill) and the paintless-step text indicator.

**Step-list compact swatch (16×16px) — PaintingModeView step list rows:**

| State | Visual |
|-------|--------|
| Resolved paint | `h-4 w-4 rounded-full` filled with `paint.hex_color` — unchanged |
| Paintless step | No swatch rendered — unchanged |
| **Unfilled slot** | `h-4 w-4 rounded-full border border-dashed border-muted-foreground bg-transparent` |

The compact unfilled-slot swatch is also a `<button type="button">` opening the
mini-dialog.

### "N colour slots unfilled" warning in PaintReadinessBanner

- Rendered only when `unfilledSlotCount > 0`.
- Sits on a second line inside the existing amber banner box, below the
  missing-paint sentence, separated by a `<Separator className="my-2" />`.
- Icon: `Circle` (Lucide, `h-4 w-4 text-muted-foreground`) — neutral, not amber,
  because unfilled is not an error.
- Text: `text-sm text-muted-foreground` — intentionally less prominent than the
  missing-paint (amber) warning.
- Copy: see Copywriting Contract.

### "from technique X" badge in SectionedTimeline

Reuse `TechniqueSectionBadge` (Phase 143, already implemented). In SectionedTimeline
the badge is display-only (non-interactive) — `onNavigate` omitted. Placement:
inline after the section name, right side of the section header row.

Source: `TechniqueSectionBadge.tsx` and `SectionedTimeline.tsx` already present in
codebase; Phase 145 passes the badge into sections that lacked it.

## Interaction States

### Unfilled-slot swatch in StepFocalView

| State | Visual |
|-------|--------|
| Default | Dashed circle swatch + `text-xs text-muted-foreground` label "Slot unfilled — tap to assign" below |
| Hover / focus | `ring-2 ring-border` on the dashed circle (same focus ring as resolved swatch) |
| Tap / click | Opens `SlotReassignMiniDialog` for that slot |
| After reassignment (dialog saved) | Swatch transitions to filled resolved swatch; label disappears |

### SlotReassignMiniDialog

| State | Visual |
|-------|--------|
| Opening | Dialog mounts; SlotFillRow pre-populated with current slot assignment (may be empty) |
| Slot unassigned | Dashed swatch + placeholder "Assign paint (optional)" — matches SlotFillDialog convention |
| Slot assigned | Filled swatch + paint name in combobox |
| Saving | "Reassign paint" button shows `<Loader2 className="animate-spin h-4 w-4 mr-2" />` and is disabled |
| Save success | Dialog closes; React Query invalidation refreshes swatch live; `toast.success("Slot updated.")` |
| Save error | `toast.error("Failed to update slot. Please try again.")` — dialog remains open |

### "N colour slots unfilled" in PaintReadinessBanner

| State | Visual |
|-------|--------|
| `unfilledSlotCount === 0` (or prop omitted) | Line not rendered; banner unchanged |
| `unfilledSlotCount > 0`, missing paints also present | Amber banner shows both the missing-paint sentence AND the unfilled-slots line (separated by Separator) |
| `unfilledSlotCount > 0`, no missing paints | Amber banner shows only the unfilled-slots line (banner still renders because unfilledSlotCount > 0) |

Note: the banner's dismissal button (`X`) dismisses the whole banner including
both lines in one action — no per-line dismiss.

### "from technique X" badge in SectionedTimeline

Display-only (non-interactive). No hover/focus state beyond default Badge secondary
styling. Identical to the display-only editor state defined in Phase 143.

  DialogHeader
    DialogTitle  "Reassign slot colour"

  identical to Phase 143 SlotFillDialog rows.

- Footer buttons: "Close" on left (outline), "Reassign paint" on right (default/accent).

## Accessibility Notes

- Unfilled-slot swatch button in StepFocalView: `type="button"`, `aria-label="Colour slot unfilled. Tap to assign a paint."`.
- Unfilled-slot swatch circle: `aria-hidden="true"` — decorative; meaning conveyed by `aria-label` on the wrapping button.
- SlotReassignMiniDialog: `DialogDescription` present (required by Radix AlertDialog a11y contract). PaintCombobox inside has `aria-label={`Paint for slot: ${slot.name}`}`.
- "N colour slots unfilled" line: uses a plain `<p>` inside the banner; `Circle` icon has `aria-hidden="true"`.
- SectionedTimeline `TechniqueSectionBadge` in display-only mode: rendered as `<Badge>` with no interactive role — no `aria-label` needed (it is read as text).
