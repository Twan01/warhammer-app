## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, gap-2 |
| md | 16px | Default element spacing, p-4 |
| lg | 24px | Section padding, p-6 gap-6 |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks, py-12 for centered states |
| 3xl | 64px | Page-level spacing |

Exceptions: none

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 |
| Label | 14px (text-sm) | 500 (medium) | 1.4 |
| Heading | 18px (text-lg) | 600 (semibold) | 1.3 |
| Display | 30px (text-3xl) | 600 (semibold) | 1.2 |

Phase-specific usage:
- **Page headers (FIX-05):** text-3xl font-semibold tracking-tight (Display role via PageHeader component)
- **Error/not-found headings (FIX-04, FIX-10):** text-lg font-semibold (Heading role)
- **Error descriptions and hints:** text-sm text-muted-foreground (Body role)
- **Escape hints (FIX-01, FIX-02):** text-xs text-muted-foreground (12px, subordinate to Body)

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(240 10% 3.9%) | Background surface (.dark --background) |
| Secondary (30%) | hsl(240 10% 5.9%) | Cards, elevated panels (.dark --card) |
| Accent (10%) | var(--faction-accent) | Faction-specific highlights only |
| Destructive | hsl(0 72.2% 50.6%) | Error icons (FIX-04), error text (FIX-09) |
| Success | green-500 (#22c55e) | Completion check icon (FIX-01) |
| Battle Gold | oklch(0.78 0.17 85) | Dark-mode only decorative token |

Accent reserved for: faction badge backgrounds, faction accent borders, sidebar active indicator

### Light-Mode Token Fallbacks (FIX-06)

These tokens are currently defined only in `.dark`. Add to `:root` as safety fallbacks:

| Token | Light-Mode Value | Rationale |
|-------|-----------------|-----------|
| `--forge-black` | `hsl(var(--background))` | Maps to white background in light mode |
| `--panel-elevated` | `hsl(var(--card))` | Maps to white card in light mode |
| `--panel-surface` | `hsl(var(--secondary))` | Maps to zinc-100 equivalent in light mode |
| `--battle-gold` | `oklch(0.55 0.17 85)` | Darker gold for white background readability |

## Copywriting Contract

### Toast Messages (FIX-03, FIX-07, FIX-08, FIX-09)

Convention: short imperative past tense, period at end.

| Element | Copy | Type |
|---------|------|------|
| Enhancement assigned | "Enhancement assigned." | toast.success |
| Enhancement removed | "Enhancement removed." | toast.success |
| Leader attached | "Leader attached." | toast.success |
| Leader detached | "Leader detached." | toast.success |
| Favorites rollback error | "Failed to update favorite. Please try again." | toast.error |
| No-op notes save | (silent -- no toast) | removed |
| Goal delete error | (single toast from hook only -- deduplicated) | toast.error |

### Error States (FIX-04, FIX-10)

| Element | Copy |
|---------|------|
| RecipesPage error heading | "Failed to load recipes" |
| RecipesPage error body | "Something went wrong" |
| RecipesPage error CTA | "Try again" (Button variant="outline", calls refetch()) |
| Army list not-found heading | "List not found" |
| Army list not-found body | "This army list may have been deleted." |
| Army list not-found CTA | "Back to Army Lists" (Button variant="ghost" size="sm" with ArrowLeft icon) |

### Painting Mode Exit (FIX-01, FIX-02)

| Element | Copy |
|---------|------|
| Completion exit button | "Exit Painting Mode" (Button, default variant) |
| Completion escape hint | "Press Escape to exit" (text-xs text-muted-foreground) |

| Not-found escape hint | "Press Escape to exit" (text-xs text-muted-foreground) |

## Interaction Contracts

### FIX-01: Painting Mode Completion Screen

| State | Visual | Interaction |
|-------|--------|-------------|
| All steps complete | CheckCircle h-16 w-16 text-green-500, "All steps complete!" text-2xl font-semibold | Exit button below message, Escape key navigates away |
| Exit button | Button default variant, full-width not needed | onClick calls onExit prop (threaded from page.tsx handleExit) |
| Escape hint | text-xs text-muted-foreground below button | Decorative only, no interaction |

### FIX-02: Painting Mode Not-Found Screen

| State | Visual | Interaction |
|-------|--------|-------------|
| Assignment not found | Centered error message | Back button + Escape key both navigate away |
| Back button | Button variant="ghost" size="sm", ArrowLeft icon h-4 w-4 mr-2 | onClick calls navigate(-1) |
| Escape hint | text-xs text-muted-foreground | Decorative only |

### FIX-04: RecipesPage Error State

| State | Visual | Interaction |
|-------|--------|-------------|
| Query error | flex flex-col items-center justify-center py-12 gap-4 | Retry button calls refetch() |
| Error icon | AlertCircle h-12 w-12 text-destructive | Decorative |
| Heading | text-lg font-semibold, "Failed to load recipes" | Static text |
| Description | text-sm text-muted-foreground mt-1, "Something went wrong" | Static text |
| Retry button | Button variant="outline" | onClick calls refetch() |

### FIX-05: Page Header Consistency

Settings page and Data Health page must render `<PageHeader title="..." />` with:
- text-3xl font-semibold tracking-tight
- border-b border-border/40
- pb-6

No custom h1 markup. Drop-in replacement of existing inline headers.

### FIX-10: Army List Loading vs Not-Found

| State | Visual | Interaction |
|-------|--------|-------------|
| isLoading=true | Existing skeleton layout (unchanged) | None -- passive loading indicator |
| isLoading=false, list=null | "List not found" centered block with back link | Back button links to /army-lists |
| Back button | Button variant="ghost" size="sm" asChild wrapping Link | ArrowLeft h-4 w-4 mr-2 + "Back to Army Lists" |

### FIX-11: Custom Scrollbar

| Property | Value |
|----------|-------|
| Scope | `.dark` selector (dark mode only) |
| Width | 6px (both width and height) |
| Track | hsl(240 5.9% 10%) -- zinc-900 equivalent |
| Thumb | hsl(240 3.7% 30%) -- zinc-700 equivalent |
| Thumb hover | hsl(240 3.7% 40%) -- zinc-600 equivalent |
| Border radius | 9999px (rounded-full) |
| Firefox | scrollbar-width: thin; scrollbar-color: thumb track |
