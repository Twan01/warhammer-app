<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local test config → committed config | The `--config` override must never mutate or leak into `tauri.conf.json` |
| Throwaway signing key → repo | A throwaway private key must never be committed or shipped |
| Local HTTP endpoint → updater | `dangerousInsecureTransportProtocol` is local-test-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-132-08 | Tampering / Supply Chain | shipping localhost endpoint or throwaway pubkey to users | mitigate | Use `tauri build --config src-tauri/local-update.json` (deep-merge, never edits committed config); checkpoint asserts `git diff --exit-code src-tauri/tauri.conf.json` clean (D-03). `local-update.json` carries placeholder pubkey only. |
| T-132-09 | Information Disclosure | throwaway private key committed | mitigate | `.gitignore` excludes `throwaway.key*`; key generated outside the repo tree; never referenced by committed config. |
| T-132-10 | Spoofing | forged update accepted in local test | accept (scoped) | Local test deliberately uses a throwaway keypair + `dangerousInsecureTransportProtocol` over localhost ONLY; production signature verification (real pubkey) is untouched (D-03). |
| T-132-SC | Tampering | npm/cargo installs | mitigate | No new packages. Do NOT use `npx serve` (unpinned auto-download, RESEARCH SUS note) — use the committed `node:http` server script or `python -m http.server`. |
</threat_model>
