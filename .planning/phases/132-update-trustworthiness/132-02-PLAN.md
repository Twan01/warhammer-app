<objective>
Make the post-install relaunch automatic so a downloaded update lands the user in the new version with no manual "Restart now" click (REL-07), while keeping an honest transitional state and a manual fallback when relaunch fails.

Purpose: today `UpdateBanner` only relaunches on a manual click. The load-bearing Windows mechanism is the NSIS `installMode: "passive"` `/R` restart (the app auto-exits mid-install on Windows, so the JS `relaunch()` is frequently a no-op there); the auto `relaunch()` is the cross-platform path + safety net. This plan makes `installMode` explicit and auto-fires `relaunch()` after install resolves.

Output: an auto-relaunch `useEffect` keyed on the `installing` state in `UpdateBanner`, an honest "Update installed — restarting…" transitional state, a preserved manual-fallback button + toast on throw (D-05), explicit `windows.installMode: "passive"` in `tauri.conf.json` (pubkey/endpoints untouched, D-03), and a Vitest spec.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Updater plugin → running app version | The installer + relaunch determine which version the user ends up running |
| Committed config → released binary | `tauri.conf.json` updater settings ship to users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-132-05 | Tampering (running-version integrity) | auto-relaunch timing | mitigate | Relaunch fires ONLY on `installing` (post-`downloadAndInstall`-resolve, D-06); never on `downloading`/mid-`Finished`, so the next launch hits the repaired DB and the user is not raced onto the old version. |
| T-132-06 | Spoofing | update signature | accept (handled by plugin) | Signature verification stays with `tauri-plugin-updater` against the committed `pubkey`; this plan does not touch `pubkey`/`endpoints` (D-03). |
| T-132-07 | Availability | failed relaunch leaves user stuck | mitigate | On `relaunch()` throw, toast + the manual "Restart now" button remain (D-05) — never a silent dead end. |
| T-132-SC | Tampering | npm/cargo installs | n/a | No new packages installed this plan — updater/process plugins already present (RESEARCH Package Legitimacy Audit: none new). |
</threat_model>
