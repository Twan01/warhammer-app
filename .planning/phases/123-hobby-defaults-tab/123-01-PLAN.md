|----------|-------------|
| User input -> app_settings | Free-text input stored as JSON TEXT in SQLite |
| app_settings -> display | JSON parsed and rendered in UI components |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-123-01 | Tampering | JSON in app_settings pipeline_labels/default_checklist | mitigate | try-catch around every JSON.parse in getBucketLabel and ChecklistDefaultsEditor; malformed values fall back to defaults, never throw |
| T-123-02 | Spoofing | Custom label text rendered in JSX | accept | React auto-escapes string interpolation in JSX text nodes; no innerHTML/dangerouslySetInnerHTML used; XSS not possible through text content |
| T-123-03 | Tampering | npm installs | accept | No new packages installed in this phase; all dnd-kit packages already in project |
</threat_model>
