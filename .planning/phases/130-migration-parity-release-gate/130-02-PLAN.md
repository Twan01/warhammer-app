| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-130-01 | Tampering / DoS | Migration checksum drift (CRLF byte change or count mismatch) breaking app launch — the root-cause bug class this milestone closes | mitigate | CR-byte gate (Buffer `.includes(0x0d)` over `migrations/*.sql`) + migration-count parity (disk === lib.rs) in `check-version.mjs`, wired to `prebuild` so no artifact is built from a drifted tree. Complements the existing `.gitattributes eol=lf` git-layer control (D-07, defense-in-depth). |
| T-130-02 | Tampering | Version representations (`package.json` vs `tauri.conf.json`) disagreeing in a shipped build | mitigate | Existing version-parity leg retained and now build-blocking via `prebuild`. |
| T-130-PT | Tampering | Path traversal in the migrations/lib.rs file reads | accept | All paths are fixed `resolve(root, ...)` — no user-supplied component; not exploitable in a single-user desktop repo. |

No npm/pip/cargo installs in this plan → no Package Legitimacy Gate.
