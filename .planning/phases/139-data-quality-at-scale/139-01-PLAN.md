<objective>
Land the DAT-01 referential-integrity validation gate FIRST (per D-08), so every subsequent
audit-correction and translation batch is validated fail-fast by both gates.

Two complementary layers (D-01):
- (a) A JSON-level referential check in the build pipeline that runs over the in-memory row
  arrays before `unit_database.json` is written, exiting non-zero on any violation — failing
  `pnpm build:udb`.
- (b) A new data-layer test that imports the built artifact into an in-memory hobbyforge.db
  (all migrations, `PRAGMA foreign_keys = ON`), runs SQLite-native `PRAGMA foreign_key_check`,
  and asserts orphan sub_faction + orphan leader-pair queries return zero rows.

Purpose: The pipeline must refuse to ship referential garbage, and a regression must turn the
Phase-131 CI test gate red.
Output: `scripts/lib/validateRefs.ts`, an extended `scripts/build-unit-db.ts` call site, and
`tests/data-layer/fk-integrity.test.ts`.
</objective>
