    **1. Add FactionCoverage interface and getPointsCoverage to diagnostics.ts:**
    Export interface FactionCoverage with fields: faction_id (string), faction_name (string), total_units (number), units_with_points (number), coverage_pct (number).

    Export async function getPointsCoverage(): Promise<FactionCoverage[]> that runs the SQL query from RESEARCH.md:
    SELECT f.id AS faction_id, f.name AS faction_name, COUNT(u.id) AS total_units,
    COUNT(CASE WHEN u.base_points IS NOT NULL OR p.unit_id IS NOT NULL THEN 1 END) AS units_with_points,
    ROUND(100.0 * COUNT(CASE WHEN u.base_points IS NOT NULL OR p.unit_id IS NOT NULL THEN 1 END) / COUNT(u.id), 1) AS coverage_pct
    FROM udb_factions f JOIN udb_units u ON u.faction_id = f.id
    LEFT JOIN (SELECT DISTINCT unit_id FROM udb_unit_points) p ON p.unit_id = u.id
    GROUP BY f.id ORDER BY f.name
