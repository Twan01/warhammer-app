## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline badge padding |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`) — matches RecipeStepRow border-pad |
| md | 16px | Default element/form spacing (`gap-4`, `p-4`) |
| lg | 24px | Section padding (`p-6`) — matches SheetContent |
| xl | 32px | Dialog body spacing |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Slot-fill row height: `p-2` (8px) top/bottom — matches TechniqueSlotRow/RecipeStepRow pattern.
- Dialog max-width: `max-w-lg` (512px) for technique picker; `max-w-md` (448px) for slot-fill.
- Section header toolbar: `p-3` (12px) — matches RecipeSectionCard existing `p-3`.
- Swatch circle: 16×16px (`h-4 w-4`), `rounded-full` — consistent with paint ownership dot in PaintCombobox.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label / field label | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Section heading / dialog title | 16px (`text-base`) | 600 (semibold) | 1.2 |
| Metadata label (uppercase) | 10px (`text-[10px]`) | 600 (semibold) | tracking-wide uppercase |

Rules:
- Dialog title: `text-base font-semibold` — matches SheetTitle sizing convention.
- Slot name in slot-fill row: `text-sm font-medium`.
- Role hint in slot-fill row: `text-xs text-muted-foreground`.
- Technique name in picker card: `text-sm font-medium`.
- Technique picker card meta (category, difficulty): `text-xs text-muted-foreground`.
- "from technique X" badge: `text-xs` — uses shadcn Badge (see Color section).
- Step count inside picker preview tree: `text-xs text-muted-foreground` — matches collapsed step count in RecipeSectionCard.

Source: conventions extracted from RecipeSectionCard, RecipeStepRow, TechniqueDetailSheet, TechniqueSlotRow.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` = zinc-950 dark | Dialog/Sheet body, page background |
| Secondary (30%) | `hsl(var(--card))` = zinc-900 dark | Picker technique cards, slot-fill row backgrounds (`bg-card`) |
| Accent (10%) | `hsl(var(--primary))` | "Apply technique" confirm button; "Edit colours" button (primary variant) |
| Destructive | `hsl(var(--destructive))` | Not applicable — no destructive actions in this phase |

Accent reserved for:
1. The primary "Apply technique" button in the slot-fill dialog footer.
2. The "Edit colours" button in RecipeDetailSheet technique-sourced section header.

All other buttons use `variant="ghost"` or `variant="outline"` — matching the recipe section toolbar pattern.

### Swatch rendering

Paint swatch in slot-fill row:
- Assigned: `h-4 w-4 rounded-full` filled with `background-color: {paint.color_hex ?? 'transparent'}`.
- Unassigned: `h-4 w-4 rounded-full border border-dashed border-muted-foreground` — visually signals "empty, not an error".
- Never show a red error state for an unassigned slot (SLOT-05: unassigned is valid).

Owned paint indicator dot in PaintCombobox (unchanged): green-500 = owned, red-500 = missing.

### "from technique X" badge

- shadcn `<Badge variant="secondary">` — `bg-secondary text-secondary-foreground`.
- Contents: `BookOpen` icon (h-3 w-3) + " from {technique.name}".
- Width: inline, max-width capped at `max-w-[200px] truncate` for long names.
- Placement: right side of the technique-sourced section header, beside the section name input (read-only display, not an input).
- In RecipeDetailSheet: badge is a `<button>` (or `<Link>`) that navigates to the technique in the library tab (APPLY-05 / CONTEXT decision). Use `variant="secondary"` Badge wrapped in a `<button type="button">` with `onClick`.
- In the recipe editor (RecipeSectionCard): badge is display-only (non-interactive in the form context).

## Interaction States

### Technique Picker Dialog

| State | Visual |
|-------|--------|
| Loading techniques | `<Skeleton>` rows, h-12 each, 3 rows, inside picker list area |
| Empty library | Centered empty state: `BookOpen` icon (h-8 w-8 text-muted-foreground) + heading + body copy (see Copywriting) |
| Search active, no results | `CommandEmpty`-style: "No techniques match your search." |
| Technique selected | Card background shifts to `bg-accent` (zinc secondary hover tint); preview panel populates right column |
| Preview loading (sections/steps/slots) | `<Skeleton>` lines in preview panel |
| Confirm disabled | "Next: Fill slots" button is `disabled` until a technique is selected |

### Slot-Fill Dialog

| State | Visual |
|-------|--------|
| Loading slot definitions | `<Skeleton>` rows, h-10 each, one per slot |
| No slots defined on technique | Body copy: "This technique has no colour slots — it will be applied with fixed paints." CTA changes to "Apply technique" (not "Next: Fill slots") |
| Slot unassigned | Dashed swatch + muted combobox placeholder "Assign paint (optional)" |
| Slot assigned | Filled swatch + paint name in combobox |
| All slots unassigned | No warning, no error — allowed per SLOT-05 |
| Saving | "Apply technique" button shows `<Loader2 className="animate-spin h-4 w-4 mr-2" />` and is disabled |
| Save error | `toast.error("Failed to apply technique. Please try again.")` — no inline error state |

### Recipe section with technique badge

| State | Visual |
|-------|--------|
| Section header (editor) | Read-only section name (Input disabled) + `TechniqueSectionBadge` (display only) + collapse toggle + NO delete button |
| Section header (detail view) | Section name as text + `TechniqueSectionBadge` (interactive link) + "Edit colours" Button ghost |
| Technique steps (editor) | RecipeStepRow with all controls disabled/read-only; paint swatch resolves via `effectivePaintId()` |
| Technique steps (detail) | Step rows read-only; swatch shows resolved paint or dashed circle if unassigned |

Disable pattern for locked technique steps in editor:
- Wrap in `pointer-events-none opacity-60` — same opacity as `isDragging ? 0.4` convention already used.
- No drag handle rendered for technique-owned steps (DnD disabled for those rows).

## Dialog Layout Contracts

### TechniquePickerDialog

```
DialogContent max-w-lg
  DialogHeader
    DialogTitle "Add technique"
    DialogDescription "Pick a technique from your library to insert into this recipe."
  Body (flex gap-4)
    Left column (flex-1)
      CommandInput (search)
      ScrollArea h-64
        List of TechniquePickerCard (one per technique)
    Right column (w-52) — hidden when nothing selected
      Preview: slots list + section/step tree (read-only, compact)
  DialogFooter
    Button variant="outline" "Close picker"
    Button variant="default" disabled={!selected} "Next: Fill slots →"
```

### SlotFillDialog

```
DialogContent max-w-md
  DialogHeader
    DialogTitle "Fill colour slots — {technique.name}"
    DialogDescription "Assign a paint to each slot. You can leave slots empty and fill them later."
  Body
    ScrollArea (if >6 slots, else plain div)
      List of SlotFillRow (one per colour slot)
  DialogFooter
    Button variant="outline" "Back to picker"
    Button variant="default" "Apply technique"
```

### SlotFillRow

```
div flex items-center gap-3 rounded-md border p-2
  div flex flex-col gap-0.5 w-36 shrink-0
    span text-sm font-medium  {slot.name}
    span text-xs text-muted-foreground  {slot.role_hint ?? "No hint"}
  SwatchCircle h-4 w-4 rounded-full  (filled or dashed)
  div flex-1
    PaintCombobox value={slotMap[slot.id]} onChange={...}
```

## Accessibility Notes

- Technique picker Dialog: `aria-label` on search input; role="listbox" implied via Command component.
- SlotFillRow: each row's PaintCombobox has `aria-label={`Paint for slot: ${slot.name}`}`.
- "from technique X" badge (interactive in detail view): is a `<button type="button">` with `aria-label="View technique {technique.name} in library"`.
- Disabled/read-only technique steps in editor: `aria-disabled="true"` on RecipeStepRow wrapper.
- Swatch circle: `aria-hidden="true"` — decorative; paint name is conveyed by combobox label.
