<objective>
Build the picker → slot-fill → insert flow that lets a user add a technique to a recipe from the section editor (APPLY-01/02/03, SLOT-05/06) and render an applied technique as a badged, locked recipe section (APPLY-04). Both dialogs are shadcn `Dialog`s mounted as SIBLINGS to the recipe editor Sheet (never nested inside SheetContent — the ApplyToUnitsDialog "P6 pitfall").

Purpose: This is the user-facing entry point to the whole Technique Library apply flow. The slot-fill control reuses the existing `PaintCombobox`; unassigned slots are valid (no validation gate). On apply, `useApplyTechnique` (Plan 02) materialises the graph and the new section appears with a "from technique X" badge, its name input disabled and no delete/drag (the saveRecipeGraph guard from Plan 01 protects its steps from edits).
Output: 5 new components + 2 extended editor components. Ends with a human-verify checkpoint for the interactive UX.
</objective>
