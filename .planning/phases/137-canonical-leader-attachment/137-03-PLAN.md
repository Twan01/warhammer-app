<objective>
Repoint the army-list builder's leader attachment off the empty `synced_leader_targets`
name-match onto the canonical `udb_leader_targets` FK join (PLAY-03). Create the batch
query `getLeaderTargetsForList(listId)`, rewrite `useLeaderTargets` to be list-keyed with
`staleTime: Infinity`, repoint `LeaderAttachmentSheet` onto an id-based valid-target set
with a permissive NULL-`udb_unit_id` fallback, and repoint the table's `isLeader`
indicator (currently fed by the same starved name-match) onto canonical pairs.

Purpose: This is PLAY-03 — replace fragile matching with real validation. Two correctness
hazards: (1) hooks-in-loop — the batch query is called ONCE at page/sheet level, never
per-row; the valid-target Map is built where the prop lands. (2) NULL fallback must be
PERMISSIVE (`null` sentinel = show ALL units) — an EMPTY set means "canonically no valid
targets". Confusing the two regresses ghost/manual-unit attachment.

Output: a new query module, a rewritten hook, a repointed sheet with permissive fallback,
a canonical isLeader indicator, and a component test covering the canonical path + NULL fallback.
</objective>
