| bundled JSON → Rust importer → SQLite | CSV-derived strings become SQL bind values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-137-03 | Tampering | CSV id strings inserted into udb_leader_targets | mitigate | sqlx positional `?` binds in the INSERT loop — id treated as data, never interpolated into SQL |
| T-137-04 | Denial of Service | oversized/garbage CSV | mitigate | Two `validUnitIds` guards bound the array to known unit ids; dedup Set; empty-string skip |
| T-137-05 | Information Disclosure | wrong column names → silent 0 pairs | mitigate | `console.warn` on missing columns / zero-pair-with-rows (A1); Task 3 confirms live header |
| T-137-SC | Tampering | npm/cargo installs | accept | No new packages this phase (RESEARCH §Package Legitimacy Audit: N/A) |

No high-severity threats: only external input is offline CSV data; all SQL is parameterized; the `validUnitIds` guard bounds the dataset.
