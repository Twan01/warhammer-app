Purpose: Without this integration plan, changing settings in the UI has no effect on the rest of the app. This plan connects each preference to its downstream consumer per D-01 through D-11.
Output: 11 modified files + 1 test file. LocaleStore removed/gutted, all consumers read from app_settings.
</objective>

    **Locale migration (D-01, D-02, PREF-01):**

    Gut `src/stores/localeStore.ts`: remove the Zustand store implementation but keep the file as a re-export shim to avoid breaking any transient imports. Export `type Locale = "en" | "fr"` and a `useLocale()` convenience hook that calls `useAppSettings()` and returns `(settings?.["locale"] ?? "en") as Locale`. This avoids the synchronous Zustand access issue — the `useAppSettings` query is cached with 5min staleTime so after first load it returns immediately. If a cleaner approach is viable after reading the current file, remove localeStore entirely and move the `Locale` type to `src/types/locale.ts`.

    Refactor `src/components/common/LocaleToggle.tsx` per D-01/D-02:
    - Remove import of `useLocaleStore`.
    - Import `useAppSettings, useUpdateSetting` from `@/hooks/useAppSettings`.
    - Import `LOCALE_QUERY_KEYS` from `@/lib/localeQueryKeys`.
    - Read current locale: extract from `useAppSettings()` data with `settings?.["locale"] ?? "en"`.
    - On toggle: call `updateSetting.mutate({ key: "locale", value: next }, { onSuccess: () => LOCALE_QUERY_KEYS.forEach(k => queryClient.invalidateQueries({ queryKey: [k] })) })`.
    - Use `useQueryClient()` from `@tanstack/react-query` for invalidation.
    - Keep the same visual UI (segmented EN/FR buttons).

    Refactor `src/hooks/useUnitDatabase.ts`:
    - Find where it imports `useLocaleStore` and reads locale.
    - Replace with either the new `useLocale()` convenience hook or inline `useAppSettings` with select. The locale value feeds into the query function as a parameter.

    Refactor `src/hooks/useDatasheet.ts`:
    - Same pattern as useUnitDatabase: replace `useLocaleStore` import with app_settings-based locale read.

    Update existing locale tests (`tests/unit-database/locale-toggle.test.ts`, `tests/unit-database/locale-store.test.ts`) to mock `useAppSettings` instead of `useLocaleStore`. If tests become irrelevant (localeStore removed), delete them and add equivalent coverage in consumerIntegration.test.tsx (Task 2).
