paint_id == null; its real paint comes from the slot map keyed by technique_step_id (unfilled

  function effectivePaintId(step: PaintResolvableStep, slotMap: SlotResolutionMap): number | null

step_photo_path, alt_paint_id — add the new field here. DraftStep already has paint_id.
